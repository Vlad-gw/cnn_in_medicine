# Воспроизведение эксперимента

## Запуск

Основной артефакт проекта: [ноутбук Colab](../notebooks/brain_mri_cnn_experiments.ipynb).

1. Открыть [в Colab](https://colab.research.google.com/github/Vlad-gw/cnn_in_medicine/blob/main/notebooks/brain_mri_cnn_experiments.ipynb).
2. Подключить доступный GPU; в исходном исследовании использовался T4.
3. В настройках выбрать `USE_GOOGLE_DRIVE = True` для сохранения весов и таблиц.
4. Указать `MANUAL_DATASET_PATH` только если загрузка Kaggle не работает.
5. Выполнить ячейки последовательно, начиная с установки `kagglehub`.

Нельзя гарантировать получение абсолютно идентичных чисел на другой версии CUDA, GPU или библиотек. Выборки фиксируются по seed 42 и сохраняются в `tables/split_manifest.csv` в Google Drive.

## Использованные параметры

| Параметр | Значение |
|--|--|
| Источник | [Kaggle: masoudnickparvar/brain-tumor-mri-dataset](https://www.kaggle.com/datasets/masoudnickparvar/brain-tumor-mri-dataset) |
| Размер входа | 160×160×3 |
| Batch size | 32 |
| Random seed | 42 |
| Train | 2 800 |
| Validation | 400 |
| Test (уникальные) | 1 584 |
| Максимум train / class | 700 |
| Максимум val / class | 100 |
| Общий бюджет этапа обучения | 30 минут |
| Fine-tuning моделей | до 8 эпох |
| Early stopping patience | 3 |

## Преобразования

- Приведение МРТ к RGB и resize 160×160.
- Приведение пикселей к тензору; нормализация средними и стандартными отклонениями ImageNet.
- Опциональная аугментация **только для Train**: поворот ±8°, сдвиг до 4%, масштаб 0,94–1,06.
- Сохранение лучшего checkpoint по minimum validation loss.

## Защита от утечек и важные оговорки

- Валидация выделялась из Training, отдельный Testing использовался для итогового сравнения.
- Проверка SHA-256 находила точные побайтовые совпадения. В конечном тестовом наборе исключены 16 точных дубликатов из 1 600 файлов.
- Близкие/почти одинаковые снимки могут остаться; patient identifiers в исходной структуре не подтверждены, поэтому строгую независимость пациентов утверждать **нельзя**.
- Не применяйте результаты как средство постановки медицинского диагноза.

## Хранение результатов

В исходной конфигурации вывод создаётся в `MyDrive/LR3_variant24_CNN_MRI`:

- `checkpoints/`: лучшие веса для моделей и состояния обучения;
- `figures/`: графики валидации и матрицы ошибок;
- `tables/`: manifest, таблицы метрик и предсказаний;
- `RESULTS_FOR_REPORT.zip`: архив графиков и аналитических таблиц (без тяжёлых весов).

**В этом репозитории намеренно нет** датасета и файлов весов моделей; для получения их нужно выполнить ноутбук.
