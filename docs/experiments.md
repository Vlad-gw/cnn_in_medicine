# Эксперименты и интерпретация результатов

## Задача

Многоклассовая классификация МРТ по четырём взаимоисключающим меткам: `glioma`, `meningioma`, `notumor`, `pituitary`.

Главная задача — сопоставить **собственную CNN, обученную с нуля**, с базовыми transfer-learning моделями и частичным fine-tuning.

## Девять конфигураций

| Конфигурация | Отличие | Роль |
|:--|:--|:--|
| `cnn_baseline` | Conv → ReLU → MaxPool, 4 блока + GAP | Собственная baseline |
| `cnn_bn` | Добавлена BatchNorm | Проверка нормализации |
| `cnn_bn_dropout` | BatchNorm + Dropout | Регуляризация |
| `cnn_bn_dropout_aug` | BatchNorm + Dropout + аугментация | Регуляризация + инвариантность |
| `resnet18` | ImageNet-веса; обучается новый FC | Transfer-learning baseline |
| `mobilenet_v3_small` | ImageNet-веса; обучается новый классификатор | Компактная transfer-модель |
| `cnn_finetuned` | Продолжение baseline, меньший LR + аугментация | Улучшенная собственная CNN |
| `resnet18_tuned` | Дополнительно обучены layer4 и FC | Fine-tuning |
| `mobilenet_v3_small_tuned` | Дополнительно обучены три последних блока и классификатор | Fine-tuning |

При обучении применялись CrossEntropyLoss, AdamW, scheduler и сохранение наилучшей версии по минимальному validation loss. Участие тестового набора в оптимизации исключено.

## Валидация (лучший checkpoint по validation loss)

| Модель | Accuracy | Validation Loss |
|:--|--:|--:|
| `cnn_baseline` | 84,75% | 0,4601 |
| `cnn_bn` | 68,75% | 0,7416 |
| `cnn_bn_dropout` | 81,75% | 0,5590 |
| `cnn_bn_dropout_aug` | 82,25% | 0,5783 |
| `resnet18` | 90,25% | 0,2927 |
| `mobilenet_v3_small` | 92,00% | 0,2703 |
| `cnn_finetuned` | 88,00% | 0,3664 |
| **`resnet18_tuned`** | **94,75%** | **0,1339** |
| `mobilenet_v3_small_tuned` | 93,50% | 0,1716 |

**Примечание:** Accuracy в таблице относится к эпохе с **минимальным validation loss**, а не обязательно к эпохе с максимальным Accuracy.

BatchNorm и некоторые сочетания регуляризации демонстрировали заметные колебания validation accuracy/loss; сама по себе BatchNorm не гарантирует улучшения, а по одному графику нельзя доказать причину нестабильности.

## Независимая тестовая выборка (1 584 изображения)

| Модель | Accuracy | Macro-F1 |
|:--|--:|--:|
| `cnn_baseline` | 75,63% | 74,51% |
| `cnn_finetuned` | 79,67% | 79,30% |
| `mobilenet_v3_small_tuned` | 86,62% | 86,09% |
| **`resnet18_tuned`** | **90,15%** | **89,93%** |

Улучшение baseline после дообучения: **+4,04 п. п. Accuracy**. Разница между лучшей ResNet18 и baseline: **+14,52 п. п.** На тесте ResNet18 распознала **1 428 из 1 584** снимков правильно.

## Анализ ошибок ResNet18 (test)

| Истинный класс | Всего | Верно | Recall |
|:--|--:|--:|--:|
| Glioma | 386 | 296 | 76,7% |
| Meningioma | 398 | 345 | 86,7% |
| No tumor | 400 | 398 | 99,5% |
| Pituitary | 400 | 389 | 97,3% |

Главная путаница: **66** изображений с истинной глиомой распознаны как менингиома. Именно этот тип ошибок наиболее перспективен для дальнейшего анализа.

### Что это означает

- Transfer learning повысил качество относительно самописной CNN при том же ограниченном объёме данных.
- Partial fine-tuning оказался полезнее обучения только классификатора.
- Одной общей Accuracy недостаточно для медицински значимой задачи: необходимо оценивать Recall каждого класса, ошибки и неопределённость.
- Результат — **только для данного публичного теста**; не доказана переносимость на другие сканеры, больницы и популяции.

## Будущие проверки

1. Убрать ограничение 700 обучающих изображений на класс, провести контроль на том же Test.
2. Дедупликация похожих снимков и patient-wise split при появлении идентификаторов пациентов.
3. Проверка изменения Recall глиомы при 224×224, class-weighting и более точном fine-tuning.
4. External validation на другом источнике и доверительные интервалы для ключевых метрик.
